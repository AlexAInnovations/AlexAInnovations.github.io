04

The Lead Scout: Christchurch

Geographic lead generation · n8n + Geoapify · GoVend, NZ · Sept 2026

Client context. GoVend is a New Zealand vending machine startup expanding into Christchurch. As a newly onboarded SDR, I inherited two connected problems: no CRM, no structured prospect list, and no repeatable way to identify which businesses in Christchurch were worth calling — high foot-traffic workplaces where a vending machine would actually get used.

The problem. Manually sweeping Google Maps suburb-by-suburb and hand-copying details into a spreadsheet doesn't scale, and it burns calling hours on research instead of conversations. The business needed a repeatable suburb sweep against its ideal customer profile, automatic enrichment instead of one-at-a-time lookups, and a clean handoff into the existing outbound calling workflow.

The build. A scheduled n8n workflow that runs weekly in four stages:

A code node cross-multiplies target suburbs against ICP categories into individual search jobs. Each suburb is geocoded via Geoapify, then queried against the Places API within a 5km radius. Results are deduplicated and enriched with phone/website/address; businesses with a website get scraped for a contact email, others pass straight through. Cleaned records land in one of two Google Sheets tabs, each row pre-tagged Ready to call, plugging directly into the existing outbound calling SOP.
